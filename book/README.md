## The governing rule

**Nothing is assumed that has not already been established.** Every prerequisite is taught here, in order, before it is needed. No silent leaps, no "it can be shown that."

## Where the papers are

The reading list is not only at the back. Each primary source appears as a **`Go and read`** panel at the point in the text where its idea is developed: Shannon beside entropy, Robbins and Monro beside SGD, Dauphin beside saddle points, each with a sentence or two on what to look for and why it is worth your afternoon.

A paper read the week you first need it lands differently from one read off a list. The back matter keeps the gathered index, now with a pointer from every entry back to its panel, so it serves as a map rather than a first encounter.

## Two kinds of code

Every algorithm is built from scratch in **NumPy**, in the body text, because a method you have written once is one you can debug and modify.

Then, and only after it has been derived, the same idea appears as practitioners actually write it: in a cyan **`In the framework`** box, with what the library is doing underneath, why it is built that way, and what it does when you get it wrong. PyTorch by default; TensorFlow only where a difference would catch you out.

The first of those boxes, in Part 0 §24, exists to prove the point: PyTorch reproduces the training step you computed by hand, digit for digit.

## How it is built

Every figure is generated by code that performs the computation it depicts. Matplotlib emits vector graphics from real runs (gradient-descent iterations, eigenvalue decompositions, measured timings); nothing is drawn by hand. KaTeX typesets the mathematics at build time, and headless Chrome prints the PDF.

```bash
cd src
npm install                 # once
node build.js               # -> ../artificial-intelligence.pdf
```

Figures are regenerated per part:

```bash
cd ../../parts/06-neural-networks && python3 make_figures.py
```

Requires Python with `pypdf` (for the cover splice) and Chrome. The cover is printed at zero margins in a separate pass and spliced in, because a full-bleed cover is impossible in a single Chrome print.
