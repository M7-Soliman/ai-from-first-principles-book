BuildThe project

Eight to twelve hours. You build a recurrent network from nothing, reproduce the field's most-cited negative result, discover it does not reproduce as stated, and find out which variable it was actually about.

P.1 What you are building

which-variable: a recurrent network in NumPy with hand-written BPTT, an LSTM cell built on top of it, and an experimental harness that varies architecture, optimiser, clipping and initialisation independently.

The rule: no claim comparing two architectures unless everything else was held fixed and you can show it. This part exists partly because that rule was broken for a decade.

P.2 Stage 1: the recurrence, forward and backward

  1. §4's forward pass, in NumPy, with $\tanh$ and a softmax output.
  2. BPTT by hand, unrolled. Remember that $\nabla W$ is a sum over all time steps.
  3. Gradient-check $U$, $V$, $W$ and both biases against central differences.
  4. Add truncation at $k$ and confirm that $k = \tau$ reproduces the full gradient exactly.

Deliverable: gradient checks passing, and Figure 2 reproduced (the relative error and the cosine of the truncated gradient against $k$). Note where the two curves separate; the direction recovering faster than the magnitude is why truncation is usable.

P.3 Stage 2: watch it fail

  1. Instrument $\|\partial\mathbf{h}^{(t)}/\partial\mathbf{h}^{(0)}\|$ and log it during training.
  2. Sweep the spectral radius of $W$ at initialisation and plot the decay, linear and $\tanh$.
  3. Find a configuration where the gradient overflows, and one where it underflows to zero.
  4. Build the scalar cliff of Figure 4 and confirm the steepness is exponential in $T$.

Deliverable: the measured spectral radius at which your model sits, tracked over training. Report whether it moves: §12 predicts that a model learning to remember will move toward the vanishing regime, and this is the cheapest way to see that.

P.4 Stage 3: the grid

The centrepiece. On a fixed long-lag task, run every cell of

{vanilla, LSTM, GRU} × {SGD, Adam} × {clipping, none} × {default bias, forget bias 1}

at four sequence lengths, five seeds each. Report every cell.

Deliverable: an attribution of the variance across the four factors. If the architecture is not the largest term, and on this task it is not, say so, and say what is. Then find the smallest change that reverses the ranking.

P.5 Stage 4: build the cell

  1. Implement the LSTM cell of §18 from the equations, forward and backward, by hand.
  2. Gradient-check it. The gates are where the errors are.
  3. Train it on a long-lag task, then read the gates out and plot them over time.
  4. Implement a GRU and confirm the parameter counts differ as §21 says.

Deliverable: Figure 7 from your own code, and the retention arithmetic (what weight does a value written at step 0 carry at step $\tau$, given your measured mean forget gate, and what would a non-gated decay of the same nominal size give?)

P.6 Stage 5: hit the bottleneck

  1. Build an encoder–decoder with an explicit context width, so it is a variable rather than an implementation detail.
  2. Choose a task whose output depends on every input token (reversal, sorting, copying), or you will measure nothing.
  3. Sweep input length and context width independently.
  4. Then instrument it: for a fixed input, measure how much of the decoder's output depends on each input position. What did the encoder keep?

Deliverable: Figure 9 from your own code, plus one paragraph on the last item. The useful finding is not that accuracy falls: it is which input positions survive, and that the encoder had to choose before knowing the question.

P.7 Stretch

  • A reservoir. Freeze the recurrence, train a linear readout in closed form, and see how close it gets. Sweep the spectral radius.
  • A dependency at exactly 200 steps, trained with truncation at 50, 100 and 400. The first two never learn it, and their loss curves look converged.
  • Packing. Measure the cost of not packing, against the variance of your sequence lengths.
  • Exposure bias. Train teacher-forced, generate free-running, and measure the drift per step. Then add a stochastic curriculum and measure it again.
  • Attention, early. Let the decoder read a weighted average of all encoder states rather than the final one, with weights from a softmax over a learned score. Rerun Stage 5. This is Part XII in twenty lines, and doing it before reading that part is the best possible preparation for it.

P.8 Done when

  • Hand-written BPTT gradient-checks, including with truncation.
  • You have produced both an overflowing and a vanishing gradient deliberately.
  • The full grid is run and the variance attributed across all four factors.
  • Your LSTM cell gradient-checks, and you have read its gates on a solved task.
  • You know what forget-gate bias your library defaults to, and what it costs.
  • The bottleneck is measured against both input length and context width.
  • Your README names one thing about recurrent networks you believed that the grid contradicted.
Why this project

Stage 3 is the reason this project exists. Every reader has been told that LSTMs solve the long-dependency problem that vanilla RNNs cannot. That claim is defensible and the standard demonstration of it varies four things at once.

Running the grid is a small experiment with a large effect on how you read papers afterwards. The specific finding, that an initialisation nobody mentions can reverse the headline, generalises far past recurrent networks, and Part XIV is built on the habit this stage teaches.

The one thing to carry forward

Recurrence shares parameters across time, and pays for it with a path length that grows with the sequence.

The parameter saving, the generalisation to unseen lengths, the vanishing and the exploding, the trade that makes them inseparable from stable memory, gating as control rather than cure, the fixed-size bottleneck, and the impossibility of training in parallel, all of it follows from that one sentence.

Which leaves the question the next part answers: can parameters be shared across positions without the path between them growing?
