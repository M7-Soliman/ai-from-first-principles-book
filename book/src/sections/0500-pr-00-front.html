Before you start

Part I gave you the objects. This chapter gives you the reason machine learning works at all: a language for reasoning when you do not, and cannot, know the answer for certain.

§0.1 The good news, and the catch

Part II is friendlier than Part I. It leans on linear algebra only lightly, so if Part I bruised you, this is a genuine chance to rebuild momentum. Most of the material is concrete: coins, dice, medical tests, counting.

The catch is that the chapter is doing two jobs at once, and the seam between them is where people get lost. The first two thirds are probability, a fairly standard tour that any statistics course would recognise. The last third is information theory, which arrives abruptly, uses unfamiliar words like entropy and divergence, and looks like a detour into a different subject.

It is not a detour. It is the destination. Information theory is where cross-entropy loss comes from: the function that essentially every classification model in existence is trained to minimise. If you have ever typed loss='categorical_crossentropy' without knowing what it meant, §25 is the section that fixes that, and §26 derives it from first principles.

Why deep learning cares: the one-paragraph version

A neural network classifier does not output an answer. It outputs a probability distribution over answers. Training it means making that predicted distribution close to the true one, which requires a way to measure the distance between two distributions, and that measure is KL divergence, which reduces to cross-entropy, which is your loss function. Every idea in that chain is defined in this chapter. Part II is not background for deep learning; it is the definition of what training is.

§0.2 What you need before page one

  • Summation. $\sum_i$ is a for loop that accumulates. Used constantly.
  • Integration, informally. $\int$ is the continuous version of $\sum$: "area under a curve". You will not compute a single integral by hand in this chapter; you only need to read them.
  • Logarithms. $\log(ab) = \log a + \log b$, and $\log$ of a small number is a large negative number. Section 21 depends on this entirely.
  • Exponentials. $e^x$ is always positive. That single fact is why the softmax function works.
  • From Part I: vectors, matrices, and (for §17 only) eigenvectors. If you skipped Part I, you can still read all of this except §17.

Notably absent: any prior statistics course. If you have taken one, you will move fast until §21 and should slow down there.

§0.4 The habit for this chapter

Part I's habit was write down the shape. This chapter's is:

Say out loud what is random and what is fixed.

Nearly all confusion in probability traces back to losing track of which symbol is a random quantity and which is a number you have already pinned down. In $p(y \mid x)$, is $x$ random? It is conditioned on, so within that expression it is treated as fixed, but it may well be random elsewhere in the same paragraph. Distributions are functions, and the question "a function of what?" is the one that keeps you oriented.
