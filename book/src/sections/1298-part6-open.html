Before you start

Part 0 §1 opened this book by claiming a neural network is a stack of matrix multiplications with a simple nonlinear function between them. Six parts later, every symbol in that sentence has been defined. This part cashes it in.

§0.2 The two things that are genuinely new

Composition as a model family. Part VI §22 argued that smoothness priors need exponentially many examples, and that the way out is a prior about compositional structure. A feedforward network is that prior made concrete: a function built by stacking simple functions, with the intermediate representations learned rather than chosen.

Differentiating it efficiently. A network has millions of parameters and one scalar loss. Computing the gradient naively (perturbing each parameter in turn) would take millions of forward passes per step. Backpropagation computes all of them in roughly the cost of one. Sections 12 to 17 are about why that is possible, and it is the algorithmic fact on which the entire field rests.

Why this part matters

Everything after this is a specialisation. Convolutional networks are feedforward networks with weight sharing and local connectivity. Recurrent networks are feedforward networks unrolled over time. Transformers are feedforward networks with a particular mechanism for deciding which inputs to combine.

None of them changes the training loop, the loss, or the differentiation. Understanding this part completely means the later ones are about architecture, which is a much smaller thing to learn than it first appears.

§0.3 The habit for this part

Know the shape and the gradient of every tensor you create.

Part I asked you to write down shapes. Here that discipline doubles: every intermediate value in a forward pass has a shape, and a corresponding gradient of exactly the same shape flowing the other way. If those two ever disagree, you have a bug, and the shape check will find it long before the loss curve does.

This is also the practical content of §15 and §21. Backpropagation is bookkeeping, and the bookkeeping is shapes.
