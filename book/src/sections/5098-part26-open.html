architecture as a declaration about symmetry

Part X priced one symmetry exactly (translation, in images) and never generalised the argument. This part does: a graph has no node ordering, a molecule has no orientation, and a set has neither. Declaring which transformations leave the answer unchanged is what an architecture is for, and here it is done for the symmetries a table and an image do not have.
