Part AThe ordering that is not there

The nodes of a graph arrive in some order, and that order is an artefact of how the data was written down. A model that reads the order is learning something about the file format. This movement establishes the requirement precisely, builds the smallest architecture that meets it, and measures what meeting it is worth.

§1 The symmetry, and where it comes from

Invariance and equivariance

Let $g$ be a transformation of the input: here, a permutation of the node labels. A function is invariant if $f(g \cdot x) = f(x)$, and equivariant if $f(g \cdot x) = g \cdot f(x)$.

A graph-level prediction should be invariant: relabelling the nodes cannot change whether a molecule is soluble. A node-level prediction should be equivariant: relabelling the nodes permutes the predictions the same way. Almost every architecture in this part is a stack of equivariant layers finished by an invariant readout, and that is the whole design pattern.

Why this is the same argument as Part X's

Part X §9 established that convolution is translation-equivariant and priced what that buys: parameters shared across positions, and a sample not needed for every location.

The general statement is that an architecture is a claim about which transformations leave the answer unchanged, and the parameter saving is the price the claim is worth. Convolution claims translation. A graph network claims permutation. A point-cloud network claims rotation. Part XXV §45 said the model family is a prior about the shape of the function; this movement says which prior, and how to build it in.

§2 Sets first

The general form of an invariant function on a set

Any permutation-invariant function of a set can be written

$$f(\{x_1, \dots, x_n\}) = \rho\!\left(\sum_{i} \phi(x_i)\right)$$

for some $\phi$ and $\rho$. Encode each element, sum, then decode. The sum is doing all the work: it is the simplest operation that does not care about order.

Mean and max are also invariant and are not equivalent. Sum can count and the other two cannot: a set of ten identical elements and a set of one give the same mean. Max is robust to the tail and discards multiplicity entirely. Which one you choose is a claim about what distinguishes your inputs, and §16's expressivity results turn on it.

The caveat that goes with "any". The claim is unconditional only if $\phi$ is free to have any output dimension you like. Wagstaff et al. (2019) show that an exact representation of every continuous invariant function on sets of size $n$ needs a latent dimension of at least $n$, and the construction fails outright on sets whose size is unbounded. In practice a fixed, finite width is chosen, which makes the representation approximate rather than exact, the same trade movement A returns to for the symmetry itself.

§3 A graph is a set with structure

The objects

A graph is a set of nodes, a set of edges, and features on either or both. Its adjacency matrix $A$ depends on the node ordering; permuting the nodes by $P$ sends $A \mapsto P A P^{\top}$, which is a similarity transform.

That last fact is useful immediately: any function of $A$ invariant under similarity (its eigenvalues, its trace, the trace of any power) is automatically permutation-invariant. The spectrum is the classical invariant, and Figure 1 uses it. Part XXVII §26 says what it is: the eigenvalues of a graph's Laplacian order its eigenvectors by how much they disagree across edges, which is exactly what frequency means on a line.

§4 What goes wrong without it

Three costs of ignoring the symmetry

Sample efficiency. A model reading a fixed ordering must learn the same fact once per ordering it meets, and there are $n!$ of them.

Variable size. A flattened adjacency matrix has a fixed dimension, so a model trained on nine-node graphs cannot read a ten-node one at all. Every architecture in movement B handles any size.

Guarantee. Even a model that has learned the symmetry approximately can violate it on an input it has not seen, and there is no way to check. A model that is invariant by construction cannot.

§5 Measured

The right reading of that

A symmetry is not something a model is incapable of learning. It is something a model spends capacity and data learning, imperfectly, when it could have been given it for nothing.

The gap here is six points of accuracy on a task where the invariant model is exact. On a larger symmetry group, with less data, or where the consequence of an inconsistent prediction is serious, that gap is the argument for the rest of this part.

§6 Invariant features, and their ceiling

Hand-built invariants, and why they are not the end

The spectrum. Eigenvalues of the adjacency or Laplacian. Invariant, informative, and Figure 1's readout.

Counts. Degrees, triangles, small subgraph counts. Invariant and interpretable.

Sorted anything. Sorting is the cheapest way to discard an order.

The limitation is that these are chosen in advance. Two graphs with the same spectrum can differ in ways that matter (cospectral non-isomorphic graphs exist), and no fixed feature set adapts to the task. Movement B's answer is to learn the invariant function instead, and movement C's is that the learned family has a ceiling too.

§7 What movement A establishes

Three things

An architecture is a claim about a symmetry, and Part X's convolution is the special case for translation. Equivariant layers with an invariant readout is the pattern.

Sum, mean and max are different claims. Only sum can count, which §16 shows is not a detail.

Building the symmetry in is exact; learning it is not. Figure 1 measures the difference as 1.000 on relabelled graphs against 0.947 for the permutation-augmented dense model; and the model that learned it approximately can still be inconsistent on an input nobody checked.
