PracticeDrills

Thirty-three problems. Most are simulations, because statistical claims are verifiable by counting; and counting is far more convincing than a derivation you half followed.

Tier 0 Estimate first

EstimateE1 · How many samples to see a difference

Two models differing by one percentage point in accuracy. Write down how many test examples per arm you need to detect that at 80% power, before working it out.

Answer. About 40,000 per arm, from n ≈ 16σ2/δ2 with σ2 = 0.25. Most people guess a few thousand. This one number explains a large fraction of the results in this field that failed to replicate. Score yourself: within a factor of two is a pass, and an order of magnitude out is worth understanding before you go on.

Tier 1 Warm-up

WarmW1 · Estimator or estimate

Which is a random variable: $\theta$, $\hat{\theta}$, or the number 4.7 you computed this morning?

Answer. $\hat{\theta}$. The truth $\theta$ is a fixed unknown; 4.7 is one realisation. The estimator is the random one, because the data was.
WarmW2 · Standard error

Data has $\sigma = 4$. You take $n = 64$ samples. What is the standard error of the mean?

Answer. $4/\sqrt{64} = 0.5$. Note it is eight times smaller than the data's spread: the estimate is far tighter than any single observation.
WarmW3 · The cost of precision

You want to halve your error bars. How much more data?

Answer. Four times as much. Error falls as $1/\sqrt{n}$, so halving it requires quadrupling $n$.
WarmW4 · Accuracy interval

A model gets 90% on 400 test examples. Roughly how wide is the 95% interval?

Answer. $\text{SE} = \sqrt{0.9 \times 0.1/400} = 0.015$, so about $\pm 3$ percentage points: $[87\%, 93\%]$. Wider than most people assume.
WarmW5 · Bias of a constant

An estimator always returns 5. The truth is 5.2. What is its bias, variance, MSE?

Answer. Bias $-0.2$, variance 0, MSE $= 0 + 0.04 = 0.04$.
WarmW6 · Degrees of freedom

Why divide by $n-1$ for the sample variance?

Answer. Deviations are measured from $\bar{x}$, which was itself fitted to the same data and sits where the squared deviations are smallest. That makes them systematically too small; $n-1$ corrects it exactly.
WarmW7 · Reading a p-value

$p = 0.02$. Which statements are wrong? (a) 2% chance the null is true (b) if the null were true, results this extreme occur 2% of the time (c) 98% chance the effect is real

Answer. (a) and (c) are wrong: both invert the conditional. (b) is the definition.
WarmW8 · Multiple tests

Twenty independent tests at $\alpha = 0.05$. Chance of at least one false positive?

Answer. $1 - 0.95^{20} = 1 - 0.358 = 0.64$. Roughly two in three.
WarmW9 · Diagnose it

Training error 1%, test error 20%. Bias or variance?

Answer. Variance: it fits the training data and not the test set. More data or more regularization; not more capacity.
WarmW10 · Irreducible error

Labels are 5% noisy. What is the best test accuracy any model can reach?

Answer. About 95%. The noise is a property of the world, and no model removes it. A model reporting 99% has learned the noise, which means it will not reproduce.

Tier 2 Core

CoreC1 · Build a sampling distribution

Draw 10,000 samples of size 20 from a skewed distribution. Histogram the sample means. Compare its spread to $\sigma/\sqrt{n}$.

Answer. Roughly Gaussian despite the skewed source (the CLT), and the measured standard deviation matches $\sigma/\sqrt{20}$ closely. Repeat with $n=5$ and the residual skew is still visible.
CoreC2 · Verify the $n-1$ correction

Estimate variance with both $n$ and $n-1$ over 20,000 samples of size 5. Compare each average to the truth.

Answer. The $n$ version averages to $\frac{4}{5}\sigma^2$, biased low by exactly $(n-1)/n$. The $n-1$ version averages to $\sigma^2$. The correction is not folklore.
CoreC3 · Confirm the MSE identity

For a deliberately biased estimator, measure bias, variance and MSE separately and check $\text{MSE} = \text{Var} + \text{Bias}^2$.

Answer. They agree to sampling error. Try a shrinkage estimator $\hat{\theta} = c\,\bar{x}$ for $c < 1$ and sweep $c$: MSE has a minimum at some $c$ strictly below 1, meaning the biased version wins.
CoreC4 · Measure coverage

Build 10,000 95% intervals and count how many contain the truth. Then repeat at $n = 5$.

Answer. About 95% at moderate $n$. At $n = 5$ with the normal formula, coverage falls to roughly 88%: that is the gap Student's $t$ exists to close. Figure 4, right panel.
CoreC5 · Bootstrap a median

Implement bootstrap_ci and use it on a median, for which no simple formula exists. Validate against a brute-force sampling distribution.

Answer. The bootstrap distribution closely tracks the true one: Figure 5. Note the median's sampling distribution is visibly non-Gaussian and lumpy for small $n$, which is exactly why you would not want to assume a formula.
CoreC6 · Bootstrap a model metric

Take a vector of per-example correctness and bootstrap a confidence interval on accuracy. Compare with the analytic $\sqrt{p(1-p)/n}$.

Answer. They agree closely for accuracy. The value of the bootstrap is that the identical code works for F1, AUC or BLEU, where no formula is at hand.
CoreC7 · p-values under the null

Compare two identical populations 10,000 times and histogram the p-values.

Answer. Uniform, with about 5% below 0.05. If your histogram is not flat, your test is miscalibrated. This is the sharpest available check that a test is correct.
CoreC8 · Power curve

Measure power against effect size for $n \in \{10, 30, 100\}$. Find the effect size at which $n=30$ reaches 80% power.

Answer. Around 0.7 standard deviations. Anything smaller and a 30-sample study will usually miss it. Figure 7.
CoreC9 · Simulate the search

Generate $k$ models with identical true accuracy, evaluate each on the same test set, report the best. Plot the optimism against $k$.

Answer. The reported best rises steadily above the truth. Nothing improved: you selected on noise. Figure 9, and the mechanism behind every leaderboard.
CoreC10 · Paired versus unpaired

Compare two models on the same test set, once treating the accuracies as independent and once analysing per-example differences. Compare interval widths.

Answer. The paired interval is substantially narrower, because shared example difficulty cancels. Same data, sharper conclusion, the cheapest improvement in this part.
CoreC11 · Bonferroni

Run 100 null tests. Count false positives at $\alpha = 0.05$, then at $\alpha/100$.

Answer. About 5 without correction, about 0.05 with. Bonferroni is crude and conservative (it costs real power), but it is one line and always defensible.
CoreC12 · MAP versus MLE

Estimate a coin's bias from $k$ heads in $n$ flips, with and without a prior favouring fairness. Sweep $n$ from 2 to 500.

Answer. At small $n$ the MAP estimate sits far closer to 0.5; by $n=500$ they are indistinguishable. Figure 10. Note MLE gives $\hat\phi = 0$ after zero heads, declaring the impossible; the prior fixes that.
CoreC13 · Weight decay is a prior

Fit ridge regression at several $\lambda$. Separately, do MAP with a Gaussian prior of variance $\tau^2$. Confirm $\lambda = 1/2\tau^2$ gives identical coefficients.

Answer. They match to numerical precision. Not analogous: identical optimisation problems, as §18 derives.
CoreC14 · Measure bias and variance

Fit polynomials of degree 0–12 on 300 fresh training sets each. Compute bias², variance and total error at held-out points. Plot all three.

Answer. You reproduce Figure 12. The key implementation point: bias needs the average prediction across training sets, so you must keep all 300 prediction vectors, not just their errors.
CoreC15 · Shrinkage beats the obvious

Estimate a mean by $\bar{x}$ and by $c\bar{x}$ for $c \in [0,1]$. Find the $c$ minimising MSE when the truth is near zero and $n$ is small.

Answer. The optimum is strictly below 1, and depends on the ratio of truth to noise. This is the whole idea of regularization, in one dimension, with no machine learning attached.
CoreC16 · Find the bug

This reports a confidence interval on accuracy. It is too narrow. Why?

acc = correct.mean()
se  = correct.std() / len(correct)
ci  = (acc - 1.96*se, acc + 1.96*se)
Answer. Divided by $n$ instead of $\sqrt{n}$. With $n = 1000$ the interval is about 32 times too narrow. The standard error is $s/\sqrt{n}$, the single most common slip in this material.

Tier 3 Stretch

StretchS1 · Reproduce double descent

Sweep random-feature model width past the number of training points. Find the peak.

Answer. The peak sits at width $\approx n_{\text{train}}$. Critical detail: you need the true minimum-norm solution. np.linalg.pinv's default rcond truncates small singular values, which is implicit regularization and erases the peak entirely; with the default the maximum sits at width 1, which is just underfitting. Pass rcond=1e-15. Figure 13.
StretchS2 · Adaptive overfitting

Simulate a researcher who repeatedly tweaks a model based on test-set feedback. Track true versus reported accuracy over 200 rounds.

Answer. Reported accuracy climbs while true accuracy is flat. Because the researcher is genuinely adaptive (each round's tweak can depend on every gap seen so far, not just on a fixed menu of $k$ candidates chosen in advance), the gap grows faster than the static max-over-$k$ rate $\sqrt{\log k / n}$ from §14; the adaptive worst case is $\sqrt{k / n}$, the result behind §15's Dwork et al. (2015) reusable holdout. This is the formal version of "the test set wears out", and it is why held-out sets are refreshed in serious benchmarks.
StretchS3 · The bootstrap can fail

Bootstrap the maximum of a sample. Compare against the true sampling distribution.

Answer. It fails badly. The bootstrap can never produce a value larger than the observed maximum, so its distribution is truncated and wrong. The bootstrap assumes the statistic depends smoothly on the distribution; extremes violate that. Knowing where a method breaks is part of owning it.
StretchS4 · False discovery rate

Implement Benjamini–Hochberg and compare against Bonferroni on 1,000 tests where 50 have real effects.

Answer. Bonferroni controls the chance of any false positive and misses most real effects. BH controls the proportion of discoveries that are false, and finds far more of the real ones. When you are screening many hypotheses, FDR is usually the quantity you actually care about.
StretchS5 · Confidence versus credible

Construct both intervals for the same problem. Find a case where they differ noticeably, and say what each is claiming.

Answer. With little data and an informative prior they diverge sharply. The confidence interval makes a claim about the procedure's long-run behaviour; the credible interval makes a claim about this parameter, and needs a prior to do so. Neither is wrong; they answer different questions, which §9 is at pains to separate.
StretchS6 · Cross-validation is biased too

Use $k$-fold CV to select among models, then report the best CV score as the performance estimate. Compare against a genuinely held-out set.

Answer. The best CV score is optimistic, for the reason in §14: you selected a maximum over many noisy estimates. Cross-validation is a good selection procedure and a biased evaluation of the selected model. Nested CV separates the two, at considerable computational cost.
