# Artificial Intelligence: from first principles

**A complete, self-contained book on AI, built from arithmetic upward.** By Soliman M.H.

Not a companion to anything, not a tutorial, not a reference for people who already know. A treatment that assumes nothing, derives everything, and does not stop until you can do the work yourself.

**[Read the book →](book/artificial-intelligence.pdf)** · 1,501 pages

---

## The governing rule

**Nothing is assumed that has not already been established.** Every prerequisite is taught here, in order, before it is needed. There are no silent leaps.

The literature splits into tutorials that show you which functions to call, and references that compress a semester into a paragraph. Each fails a different reader. This is the thing in between.

### How a part gets built

Each part folder holds a full toolchain: matplotlib generates every figure from real computation, KaTeX renders the mathematics server-side, and Chrome headless prints the PDF. The build fails loudly on parse errors, broken figures, or unrendered LaTeX.

```bash
cd book/src
npm install && python3 ../../parts/<NN>-<name>/make_figures.py && node build.js
```

## About the source material

This book is built around **[*Deep Learning*](http://www.deeplearningbook.org/) by Ian Goodfellow, Yoshua Bengio, and Aaron Courville** (MIT Press, 2016). The book is available to read free online at [deeplearningbook.org](http://www.deeplearningbook.org/).

The scope comes from the source; the content does not. Every derivation, figure, drill and project here is original. The coverage follows the chapters closely but the treatment is deliberately different: more derivation, more history, more measurement, and everything built from what the book has already established. Two parts (Part 0 and Part IV) have no source chapter at all; both were added because the governing rule demanded them.

**If this book helps you, buy a copy of the source.** It supports the authors and everyone who put the work in. [Amazon](https://www.amazon.com/Deep-Learning-Adaptive-Computation-Machine/dp/0262035618).
